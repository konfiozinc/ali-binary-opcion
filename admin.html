🤖 ESTADO DEL BOT IQ OPTION
Desconectado El bot envía señales automáticamente cuando está activo

El bot se integra vía webhook — envía una señal POST a Firestore con el secreto configurado. No requiere servidor propio si se usa desde Python/Node.js local.

🧪 PROBAR SEÑAL DE BOT
📋 CÓDIGO DE INTEGRACIÓN — PYTHON

Usa este script en tu bot de IQ Option para enviar señales automáticamente:

import firebase_admin from firebase_admin import credentials, firestore from datetime import datetime # Inicializar Firebase cred = credentials.Certificate("serviceAccountKey.json") firebase_admin.initialize_app(cred) db = firestore.client() def send_signal(asset, direction, entry_mm, entry_ss, expiration, strategy="", confidence=0): """Envía una señal a la sala en tiempo real""" signal = { "asset": asset, "broker": "IQ Option", "direction": direction, # "CALL" o "PUT" "entryTime": f"{entry_mm:02d}:{entry_ss:02d}", "expiration": str(expiration), "status": "pending", "source": "bot", "botName": "IQBot-Auto", "strategy": strategy, "confidence": confidence, "createdAt": firestore.SERVER_TIMESTAMP } ref = db.collection("signals").add(signal) print(f"✅ Señal enviada: {asset} {direction} — ID: {ref[1].id}") return ref[1].id # Ejemplo de uso: # send_signal("EUR/USD OTC", "CALL", 45, 0, 1, "RSI+MACD", 87)
📋 CÓDIGO DE INTEGRACIÓN — NODE.JS
const admin = require('firebase-admin'); const serviceAccount = require('./serviceAccountKey.json'); admin.initializeApp({ credential: admin.credential.cert(serviceAccount) }); const db = admin.firestore(); async function sendSignal(asset, direction, entryTime, expiration, strategy = '', confidence = 0) { const signal = { asset, broker: 'IQ Option', direction, entryTime, expiration: String(expiration), status: 'pending', source: 'bot', botName: 'IQBot-Node', strategy, confidence, createdAt: admin.firestore.FieldValue.serverTimestamp() }; const ref = await db.collection('signals').add(signal); console.log(`✅ Signal sent: ${asset} ${direction} — ID: ${ref.id}`); return ref.id; } // Ejemplo: // sendSignal('EUR/USD OTC', 'CALL', '45:00', 1, 'RSI', 85);
🔑 PASOS PARA ACTIVAR EL BOT
1. En Firebase Console → ⚙️ Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada → Guarda el JSON como serviceAccountKey.json
2. Instala el SDK: pip install firebase-admin (Python) o npm install firebase-admin (Node)
3. Usa la función send_signal() desde tu lógica de bot — cuando detectes una entrada, llama la función y la señal aparecerá en la sala de usuarios al instante
4. Para marcar resultados automáticamente, actualiza el campo status del documento a "win", "loss" o "draw"
